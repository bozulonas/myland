
### Flexible Casting 
The documented spell, invocation or magic item effects are only those which are currently known. Astute & reckless practitioners can attempt new ways to apply them.

When casting, the PC declares the intended effect *(even if it differs from the written description)*, the GM adjudicates it's minimum Power, see [example power](#example-powwr) below.
#### Example Power
Use the examples below as guidance for the minim power required for a spell given it's desired effect.


| Example Spell     | Power 1           | Power 2-3           | Power 4                 |
| ----------------- | ----------------- | ------------------- | ----------------------- |
| Vermin Tongue     | Speak with vermin | Command a swarm     | Swarm a whole city      |
| Jovial Wings      | Levitate          | Fly high in the sky | Grow real wings         |
| Healing domain    | Restore hp        | Restore STR         | Regrow a limb           |
| Warding domain    | Shield yourself   | Shield all allies   | Build a town wall       |
| Demon Calling     | Summon an imp     | Summon a hellhound  | Summon a demon          |
| Cleansing Whisper | Clear a condition | Cleanse a poison    | Cleanse a town's blight |
